# 자기통제 (Self-Control PWA)

수험생용 단일 사용자 PWA. **수면 강제 · 숏폼 억제 · 공부 타이머** 세 가지만 담았습니다.
서버 없음 — 모든 기록은 폰 안 IndexedDB에만 저장되고 오프라인에서 동작합니다.

## 폰에 설치하기

1. GitHub 저장소 → **Settings → Pages** → Source: `main` 브랜치 / `/docs` 폴더 → Save
2. 몇 분 뒤 나오는 주소(`https://<계정>.github.io/study-ai/`)를 **폰 브라우저**로 엽니다.
3. **iPhone**: 공유 버튼 → *홈 화면에 추가* · **Android**: 메뉴 → *앱 설치*
4. 홈 화면 아이콘으로 열고, 설정 탭에서 **알림 켜기**를 누릅니다.
   (iOS는 홈 화면에 추가한 상태에서만 알림 권한이 뜹니다. iOS 16.4 이상)

## 화면

| 탭 | 하는 일 |
|---|---|
| 홈 | 스트릭, 오늘 밤 상태, 최근 7일 요약, 충동 버튼 |
| 수면 | 취침/기상 체크인, 7일 기록, 잠금 규칙 |
| 숏폼 | 충동 버튼, 시간대별 패턴, 감정·상황 통계 |
| 타이머 | 과목 선택 → 뽀모도로 → 집중도 1~5 기록 |
| 설정 | 목표 시각, 다짐 문장, 대기 시간, 백업 |

## 동작 규칙

- 취침 목표 **N분 전**(기본 30분)부터 앱 전체가 잠깁니다. 다짐 문장을 한 글자도 틀리지 않게
  타이핑해야 열리고, 열어도 기본 10분 뒤 다시 잠깁니다.
- `지금 잔다`를 누르면 기상 체크인 전까지 앱이 완전히 잠깁니다.
- 취침 체크인이 목표 **+30분** 이내, 기상 체크인이 목표 **+20분** 이내여야 그날 성공 → 스트릭 유지.
- 숏폼 버튼은 60초 대기 + 감정 선택 + 이유 한 줄을 채워야 다음으로 넘어갑니다.
- "하루"의 경계는 **새벽 4시**입니다. 새벽 2시 기록은 전날로 집계됩니다.

## 웹앱의 한계 (설계상 감안한 것)

- **앱 차단 불가**: 인스타·틱톡을 OS 레벨에서 막을 수 없습니다. 진짜 차단은
  iPhone *스크린타임 → 앱 시간 제한*, Android *디지털 웰빙 → 앱 타이머*로 걸어두세요.
- **예약 알림 불가**: 서버 푸시가 없어 앱이 꺼진 동안에는 알림이 울리지 않습니다.
  기상 알림은 폰 기본 알람과 병행하고, 이 앱에서는 체크인만 하세요.
  놓친 알림은 다음에 앱을 열 때 알려줍니다.
- **진동**: Android만 지원. iOS는 소리·알림으로 대체합니다.
- **데이터 소실**: 브라우저 데이터를 지우면 전부 사라집니다. 설정 → 백업 내보내기를
  주 1회 실행해 파일을 나에게 보내두세요.
