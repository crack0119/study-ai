# 5대5 표준점수 대항전 트래커

10월 고3 모의고사 표준점수로 두 팀이 겨루는 웹앱입니다. 서버도 계정도 없고,
모든 기록은 브라우저 localStorage 안에만 남습니다.

## 실행

```bash
cd score-battle
npm install
npm run dev      # http://localhost:5173
```

빌드는 `npm run build`, 빌드 결과 확인은 `npm run preview`.

## 화면

| 탭 | 하는 일 |
|---|---|
| 입력 | 참가자를 고르고 선택과목·표준점수를 넣습니다. 입력 즉시 저장됩니다. |
| 스코어보드 | 양 팀 총점·점수 차·승리 팀, 팀별 개인 점수. 결과 카드를 PNG로 저장·공유합니다. |
| 비교 | 과목별 팀 평균 그래프, 기여도 순위(팀 내/전체), MVP. |
| 구제 | 패배 팀 5명 중 1명을 벌칙에서 빼는 룰렛. 랜덤·수동 지정 두 가지. |
| 기록 | 회차 관리, 상대 전적, 영어 환산·테마 설정, JSON 내보내기/불러오기, 전체 초기화. |

## 점수 규칙

- **국어** 공통 + 선택 1개(화법과작문 / 언어와매체) → 표준점수 하나
- **수학** 공통 + 선택 1개(확률과통계 / 미적분 / 기하) → 표준점수 하나
- **탐구** 2과목, 각각 표준점수. 사탐(생활과 윤리·사회·문화)과 과탐(Ⅰ·Ⅱ 전 과목) 중 자유 선택
- **영어·한국사** 절대평가라 표준점수가 없어 기본값은 승부 계산에서 제외.
  기록 탭의 *영어 등급 환산*을 켜면 등급표(기본 1등급 140 … 9등급 60, 수정 가능)대로 합계에 더합니다.
- **팀 점수** = 팀원 5명의 (국어 + 수학 + 탐구① + 탐구②) 합
- 표준점수는 **0~200 정수**만 받습니다. 소수점·범위 밖 값은 저장되지 않고 그 자리에서 이유를 알려 줍니다.
- 미입력자가 한 명이라도 있으면 **잠정 결과**로 표시하고 누가 안 냈는지 이름을 보여 줍니다.

## 회차와 전적

회차를 새로 만들면 그 회차의 점수·구제 결과가 따로 쌓입니다.
기록 탭에서 **‘전적에 반영’**을 켠 회차만 상대 전적(1승 1패)으로 셉니다.
입력 중인 회차는 꺼 두면 됩니다.

## 구제 룰렛

- 패배 팀 5명이 룰렛에 오릅니다. 팀 내 기여도 1위는 *구제 추천 후보*로 판에 점선 표시됩니다.
- 한 번 돌리면 결과가 고정되고 다시 돌릴 수 없습니다. 되돌리려면 **결과 되돌리기**(확인 모달)를 눌러야 합니다.

## 데이터

- 저장 위치: `localStorage["score-battle:v1"]` — 이 브라우저에만 있습니다.
- 기록 탭에서 JSON으로 내보내고 불러올 수 있습니다. 불러오기는 현재 데이터를 통째로 덮어씁니다.
- 폰을 바꾸거나 브라우저 데이터를 지우면 사라지니, 중요한 회차는 내보내기로 백업하세요.

## 구조

```
src/
├─ data/       roster.ts(명단) · subjects.ts(과목 카탈로그) · defaults.ts(기본값)
├─ lib/        score.ts(점수 계산) · storage.ts(저장·JSON) · rng.ts · format.ts
├─ store/      AppStore.tsx (Context + useReducer, localStorage 동기화)
├─ screens/    Entry · Scoreboard · Compare · Rescue · History
└─ components/ 공용 UI, 룰렛, 결과 카드, 차트
```

점수 계산은 전부 `lib/score.ts`의 순수 함수로 모아 두었고, 화면은 그 결과만 그립니다.
